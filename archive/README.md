# Archive — superseded first revision of the report

This directory holds the **first revision** of the project report exactly as it
was written, in longform and in its per-section form. It is kept unchanged as a
record of what was concluded at that time and on what evidence.

**It is superseded and its conclusions are out of date.** In particular, the
first revision states that no simulation had been run outside approximately
25.6 to 26.6 GHz, that the reconstructed element does not tune, and that the
immediate next experiment is a wider-frequency sweep. That sweep has since been
run (runs 17 and 18, approximately 25.5 to 28 GHz), and the current statement of
the result is:

> The current reconstruction shows capacitance-dependent resonant behaviour, but
> the tunable resonant region is displaced above the intended 26.104 GHz
> operating point.

Nothing in this directory has been edited to match that. Rewriting a superseded
record would hide how the earlier conclusion was reached.

For the current position see the [README](../README.md),
[`docs/project_state.md`](../docs/project_state.md),
[`docs/claims_ledger.md`](../docs/claims_ledger.md) and the current report in
[`report/`](../report/) and [`deliverables/`](../deliverables/).
