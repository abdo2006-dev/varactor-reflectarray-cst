# CST reconstruction views

Screenshots of the reconstructed unit cell in CST Studio Suite 2023, all taken
from the current geometry checkpoint recorded in
[`../../docs/project_state.md`](../../docs/project_state.md).

Every image in this directory is our own model. No image here is reproduced from
a publication; reproduced source figures live in `../source/` and carry their
licence and attribution there.

| File | View |
|---|---|
| `model_isometric.png` | Overall isometric view of the unit cell |
| `model_layer_stack.png` | Side view through the stack, showing the conductor layers |
| `model_side_view.png` | Side view of the bias path and blind via |
| `model_via_detail.png` | Blind via and varactor terminal detail |
| `model_front.png` | Front view |
| `model_back.png` | Back view |
| `model_bias_network_detail_1.png` | Bias-T branch and radial stub, detail |
| `model_bias_network_detail_2.png` | Bias-T branch and radial stub, second detail |
