# Prompts

Prompts and instructions used with Claude Code while building this repository
and drafting the report.

They are kept for reproducibility: the report is an evidence-controlled
document, and the constraints given to the writing tool are part of how that
control was enforced.

## Contents

`initial_repository_and_report_brief.md` is the brief that produced the first
version of this repository, including the report architecture, the evidence
classification rules, the anti-redundancy rules, the academic writing
constraints and the prohibition on converting assumptions into facts or planned
experiments into results.

## Note

These files record instructions, not results. Nothing in this directory is
evidence for any claim in the report.
